# cards-segment

Custom **cards** block. Purpose: 4-up edge-to-edge tall portrait image tiles, each tile fully linked, with an uppercase label at the bottom.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tile: image cell | label cell containing a link (the link target becomes the whole-tile link).

No variations.
