# hero-video

Custom **hero** block. Purpose: full-bleed band with a looping, muted background video (Vimeo/YouTube/mp4 link) and overlaid white text, no CTA.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1: background cell holding a video link (e.g. https://vimeo.com/963210681) and/or a poster image; row 2: content cell with a heading or statement paragraph, optional description and optional CTA link.
