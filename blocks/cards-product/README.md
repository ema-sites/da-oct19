# cards-product

Custom **cards** block. Purpose: 2-up full-bleed photo cards with overlay text: eyebrow, heading (or logo image), description, pill CTA and optional footnote.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card: background image cell | text cell with optional eyebrow paragraph, heading (or logo image), description, CTA link, optional footnote paragraph after the CTA.
